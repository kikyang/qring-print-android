## v0.7.8（2026-09-28）统一「准备打印页」

### 新增
- **准备打印页**：文字 / 图片 / 条码 / 文档 / 模板 / 错题卡 / 函数图像 / 自检页 / 批量
  等 **11 处打印入口全部汇聚**到同一个页内准备页——
  - **大图预览**由**待打印的 1-bit 光栅直出**（所见即所打），不是另画一张示意图；
  - **打印设置**（浓度 淡/中/浓、前走纸、后走纸、份数 1~10）**与预览同屏**，改完就地可见；
  - 确认无误再点「🖨 打印」，想改内容点「← 返回修改」回到原界面（回到原来的二级 Tab 与表单）。
- **模板生成后可先看大图**：课程表 / 单词表 / 每日计划 / 口算题等生成后先进准备页，不再直接弹确认框。
- **批量打印**：准备页显示**首条预览 + 总条数**，确认后整批连续打印。

### 改进
- 各处的「打印」按钮统一为「**下一步：准备打印 →**」，行为一致（此前文字页要手点一次「预览打印效果」、
  模板类则连预览都没有直接弹窗）。
- 确认条（浓度 / 走纸 / 份数）抽成**两条入口共用的同一构造器**，快速打印与准备页不会再各改各的。

### 修复
- 从准备页返回时，原工作区表单可能停在不可见状态（`RadioGroup.check()` 对**已选中**项不触发监听器所致）。
  已修，并加了回归用例。

### 质量
- **213 例自动化测试全过**（新增 3 例：准备页确认条在 ScrollView 内、返回回到原工作区、模板生成后进准备页；
  另加 1 例**发版一致性守卫**：`build.gradle` versionName / `ReleaseNotes` 最新条目 / 仓库 `version.json`
  三处必须同号，防「发版漏同步」，已做回滚验证）
- R8 release APK **1,043,092 字节**（v0.7.7 为 1,035,488，+0.73%）；Android 13+（minSdk 33），需授予蓝牙权限

## v0.7.7（2026-09-09）修复「检查更新」漏报新版本

### 修复
- **「检查更新」漏报新版本**：更新检查改为**多个源都取、按版本号取最高**。
  此前实现是「谁先成功用谁」，而第一优先级是 jsDelivr 的版本列表接口——
  它的索引会**长期滞后**（实测 v0.7.5 发布 8 天后、v0.7.6 发布当天都没被收录，
  但 `@v{version}` 显式路径一直正常），导致 0.7.4 及以上用户点检查更新只会看到
  「已是最新」，**永远收不到更新提示**。现三个源（jsDelivr 版本列表 / 仓库
  `@main/version.json` / GitHub API）各自取回后按版本号比大小取最大。
- 下载仍走 jsDelivr 的 `@v{tag}` 路径（tag 不可变，无缓存滞后问题）。

### 说明
- 本版同时包含 **v0.7.6** 的全部内容（0.7.6 未单独发布过）：
  - 界面主题改为 **8 套差异化风格**（紫罗兰 / 墨绿纸感 / 暗色效能 / 手账纸感 /
    热敏黑白 / 奶油多彩 / Apple Bento / 玻璃拟态），移除旧微信风/简洁风/蓝白风
  - 「我的 → 界面主题」改为竖向列表（色卡 + 名称 + 勾选态）
  - 修复打印确认对话框遮挡（issue #5）：较高图片时「确认打印」按钮被挤出屏幕且无法滚动
  - 图片抖动改**蛇形扫描**：消除照片中间调的蠕虫纹/竖条纹

### 质量
- **210 例自动化测试全过**（新增 UpdateManagerTest 9 例：多源择优 + 三种源解析 + 坏 JSON 容错）
- R8 release APK 约 1.0MB
- Android 13+（minSdk 33），需授予蓝牙权限
