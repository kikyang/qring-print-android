## v0.4.0（2026-08-11）

### 重大更新
- **UI 全量改版**：微信小程序风格（灰底白卡、微信绿 #07C160、8px 圆角、线性图标，支持深色模式）
- **双通道连接**：BLE 透传 + 经典蓝牙 SPP 自动探测（AUTO 模式先试 BLE 并用状态查询验证，无响应自动回退），覆盖 X1 各软件版本；连接进度条对话框
- **描边黑白化**：Canny 线稿 / LINES 描边（灵敏度/线宽/平滑/反白）+ 二值化阈值滑块（与打印浓度独立）+ 对比度调节
- **文档打印**（零依赖）：PDF 逐页渲染、Word（docx 文本 / 老格式 doc OLE2）、Excel（xlsx 表格 / 老格式 xls）、TXT（GBK/UTF-8 自动识别）

### 稳定性
- OOM 防护（大文件流式读取/高度上限/Error 单独捕获）
- 文档解析竞态修复、大文件截断保护、连接/解析进度反馈

### 安装要求
Android 13+（minSdk 33），需授予蓝牙权限。

功能详见 README。
