## v0.7.7（2026-09-09）修复「检查更新」漏报新版本

### 修复
- **「检查更新」漏报新版本**：更新检查改为**多个源都取、按版本号取最高**。
  此前实现是「谁先成功用谁」，而第一优先级是 jsDelivr 的版本列表接口——
  它的索引会**长期滞后**（实测 v0.7.5 发布 8 天后、v0.7.6 发布当天都没被收录，
  但 `@v{version}` 显式路径一直正常），导致 0.7.4 及以上用户点检查更新只会看到
  「已是最新」，**永远收不到更新提示**。现三个源（jsDelivr 版本列表 / 仓库
  `@main/version.json` / GitHub API）各自取回后按版本号比大小取最大。
- 下载仍走 jsDelivr 的 `@v{tag}` 路径（tag 不可变，无缓存滞后问题）。

### 说明
- 本版同时包含 **v0.7.6** 的全部内容（0.7.6 未单独发布过）：
  - 界面主题改为 **8 套差异化风格**（紫罗兰 / 墨绿纸感 / 暗色效能 / 手账纸感 /
    热敏黑白 / 奶油多彩 / Apple Bento / 玻璃拟态），移除旧微信风/简洁风/蓝白风
  - 「我的 → 界面主题」改为竖向列表（色卡 + 名称 + 勾选态）
  - 修复打印确认对话框遮挡（issue #5）：较高图片时「确认打印」按钮被挤出屏幕且无法滚动
  - 图片抖动改**蛇形扫描**：消除照片中间调的蠕虫纹/竖条纹
