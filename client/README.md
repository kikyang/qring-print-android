# 替代打印客户端

> 最终交付物所在。实物到位、协议确认后开发。

## 预期形态

- 首选：**Python 脚本**（Windows + 蓝牙适配器，pybluez / bleak 按蓝牙类型选择）
- 备选：Node.js 脚本（tiny-esc-pos）或小网页（Web Bluetooth，Chrome 支持 BLE）

## 功能清单

- [ ] 连接打印机
- [ ] 文本 → 位图/指令编码（含中文，需处理字体栅格化）
- [ ] 打印测试页
- [ ] 错题格式：题号 + 题干 + 答案排版

## 中文打印注意

- 热敏打印中文通常走**位图打印**（图片栅格化后 `GS v 0` 输出），直接发 GBK 文本指令在私有协议下不一定支持
- 或确认协议是否支持 GBK 文本模式
