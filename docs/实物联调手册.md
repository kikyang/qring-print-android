# 错题小印 · 实物联调手册

> 实物到位后按本手册从零走到能正常打印。全程预计 30-60 分钟。
> 涉及协议细节见 `docs/protocol.md`，对照表见文末"预期响应表"。

---

## 第 0 步：清点与准备

| 需要 | 说明 |
|---|---|
| 错题小印打印机实物 | 带电池、纸卷（58mm 热敏纸） |
| 红米 K80 Pro | 已开蓝牙，允许"未知来源"安装 |
| APK 文件 | `android\app\build\outputs\apk\debug\app-debug.apk`（已构建好） |
| 电脑（可选） | 需要 adb 装 APK 时用 |

**先确认机器能开机**：装上电池，长按电源键，指示灯亮、能听到上电声。

---

## 第 1 步：安装 APK 到手机

**方式 A：USB 调试（推荐，出错少）**
1. 手机：设置 → 我的设备 → 全部参数 → 连点 7 次"OS 版本"开启开发者模式
2. 设置 → 更多设置 → 开发者选项 → 打开 **USB 调试**
3. USB 线连电脑，手机弹窗选"允许调试"
4. 电脑执行：
   ```
   adb install app-debug.apk
   ```

**方式 B：直接侧载**
1. 把 APK 拷到手机（微信文件传输/数据线）
2. 文件管理器点开安装 → 首次提示"未知来源"时允许

**首次打开 App**：允许蓝牙权限（弹窗点允许；Android 12+ 会请求"附近设备"权限，全部允许）。

---

## 第 2 步：配对打印机

1. 打印机**开机**
2. App 点"刷新设备列表"
   - **已配对**：直接显示"已配对设备"，点它连接
   - **未配对**：下方会出现"发现未配对的打印机（点按打开蓝牙设置配对）"→ 点它跳系统设置 → 找到 Qring 开头设备 → 配对（如要 PIN 试 0000 或 1234）→ 回 App 点"刷新"
3. **预期**：点连接后状态栏显示：
   ```
   已连接 XXX
   型号: XXXX
   固件: XXXX
   电量: XX%
   ```
   出现这三行 = 协议通道打通，跳到第 3 步。

**连接失败的排查**：
- 打印机没开机 / 离手机太远（<1 米试）
- 没授予蓝牙权限 → 系统设置里给 App 授权
- 已配对但连不上 → 系统蓝牙设置里删掉设备重新配对一次

---

## 第 3 步：协议核对（用调试台，最关键）

主界面点"**调试台（收发日志/原始命令）**"，逐条执行快捷命令，对照预期：

| 快捷命令 | 发送字节 | 预期响应 | 验证点 |
|---|---|---|---|
| 查状态 | `10 FF 40` | 1 字节 `00` | 状态字节解析正确 |
| 查电量 | `10 FF 50 F1` | 2 字节，**第 2 字节=百分比**（如 `01 64`=100%） | 电量通道正确 |
| 查型号 | `10 FF 20 F0` | ASCII 字符串 | 型号识别 |
| 查固件 | `10 FF 20 F1` | ASCII 字符串 | 固件版本 |
| 走纸 50 点 | `1B 4A 32` | 纸**走出一小段**（约 6mm） | ESC J 命令有效 |
| 唤醒 | 12×`00` | 无响应但后续命令正常 | 唤醒前置位 |
| 使能+停 | `10 FF F1 02 1F B2 10 10 FF F1 45` | 无响应，正常 | 打印使能段 |

**结果判定**：
- ✅ **全部符合** → 协议与开源逆向完全一致，跳到第 4 步
- ⚠️ **部分不符**（如状态字节总是 `FF`）→ 截图日志（调试台"复制/分享"），发回来分析；大概率是固件版本差异，对照 `docs/protocol.md` 调整
- ❌ **完全无响应** → 确认唤醒后重试；仍不行检查是否为纯 BLE 机型（SPP 不通），再做 BLE 通道

> 调试台日志每步都在记录（格式：`HH:mm:ss T/R 字节hex`），所有实测证据都在里面。

---

## 第 4 步：打印自检页（浓度校准）

1. 主界面"**打印自检页（5 档浓度对比）**"——会连打 5 页，浓度 0~4
2. 等 5 页全部打完（每页有 5 组横线 + 线条粗细 + 灰度渐变 + 文字）
3. **对比 5 页，选最佳浓度档**：
   - 横线最实、1 点线条能看清、文字不糊 = 最佳
   - 偏淡（线条断）→ 选更高浓度档
   - 偏浓（文字糊成一片）→ 选更低浓度档
4. 记下最佳档位 → **后续所有打印统一用这个浓度**

> ⚠️ **通道差异（2026-08-13 实测）**：同浓度下 SPP 比 BLE 墨色更深更实（传输节奏不同导致
> 打印头残热积累差异，见联调记录表"其他异常"）。浓度定稿 2 是 BLE 下选的；
> 若主要走 SPP 且嫌黑，打印设置里调到 **1** 观感接近 BLE 的 2。

> 临时改浓度：调试台发 `10 FF 10 00 N`（N=0~4），再打一页自检确认。
> 定稿后把最佳浓度写进代码默认值（改 `MainActivity` 里 `thickness = 1`）。

## 常见问题排查表

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 点连接一直"正在连接" | 打印机没开机 / 已配对但不在线 | 确认开机；系统设置删配对重配 |
| 连接失败"错误码" | Android 12+ 权限没给 | 系统设置 → 应用 → 权限 → 附近设备 |
| 打印没反应 | 未发送唤醒 / 浓度太低 | 调试台先发"唤醒"再试；查日志看命令是否发出 |
| 打印一半停 | 缺纸/开盖/过热（打印完成前会断） | 看状态栏拦截提示；FF xx 故障码对照：01 缺纸 02 开盖 03 过热 04 低电 |
| 打出来全黑/全白 | 光栅编码问题 | 日志核对 GS v 0 头（`1D 76 30 00 30 00 ...`）；widthBytes 应为 48 |
| 文字模糊 | 浓度档不合适 | 自检页重选浓度 |
| 状态读数不准 | 协议非标准（10 FF 系列） | 确认用的是快捷命令而非标准 DLE EOT |
| 打印很慢（BLE 通道） | BLE 分包 32B + 80ms 间隔（防丢包实测定稿） | 换 SPP 通道（AUTO 默认已优先）大幅提速 |
